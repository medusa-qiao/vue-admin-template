# Vue 组件、状态与样式验收

本页沿用项目已安装的 Vue、Element Plus 和 Tailwind，不新增 UI 库或类名工具。自定义组件的设计依据从 [Element Plus 设计概览](../../element-plus-skills/element-plus-design-overview/SKILL.md) 开始，继续读取与任务对应的组件和设计技能。

## 组件组合

- 表单、按钮、表格、弹层优先使用当前已注册的 Element Plus 组件及项目包装；实际注册情况查 `src/plugins/elementPlus.ts`。
- Vue SFC 使用 `<script setup lang="ts">`，显式声明 props、emits 和状态。跨页复用后再把样式与交互提取为公共组件。
- Tailwind 负责排列和间距，组件已有的尺寸、loading、disabled、校验等状态使用组件自身 API。修改这些行为时读取对应 `el-*` 指南和当前组件源码。
- Props 驱动的样式使用 Vue `:class` 或计算属性；保留完整类名，便于检索、检查和维护。不要把业务状态仅表达为颜色。

## 局部覆盖

先检查组件提供的 props、slots 和主题变量。确实需要修改内部结构时，使用当前项目的局部样式方式，将 `:deep()` 限定在业务容器内。全局变量与通用样式集中在 `src/style/`，页面不要重复注册主题开关或全局 reset。

自定义内容的颜色引用对应 `--el-*` token 或已有 Tailwind 映射；默认色值仅供理解设计，不能直接变成项目中的固定配色。尺寸、间距、圆角和阴影依据设计参考与相近组件选取。

## 交互与验收

| 检查         | 关注点                                                 |
| ------------ | ------------------------------------------------------ |
| 主题与暗色   | 背景、正文、边框、浮层随平台主题变化                   |
| 键盘与焦点   | 操作可聚焦、可触发；错误有可识别说明                   |
| 禁用与加载   | 除视觉变化外还阻止重复操作；失败恢复可操作状态         |
| 窄屏与长文本 | 内容可读，操作不会被遮挡，必要滚动范围明确             |
| 表单与弹层   | 校验信息可见，提交失败保留输入，关闭与取消符合既有交互 |

执行目标项目要求的代码与样式检查，并在浏览器查看实际效果。普通文案或可逆样式调整无需新增只复述实现的单元测试。
